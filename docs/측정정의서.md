| 항목 | 값 | 비고 |
|---|---|---|
| 셀 크기 | 2.5m × 2.5m 정사각형 | |
| 차량 | 1×2셀 (2.5×5m) | 이동 중 AGV+차량 = 1×2 강체 |
| 통로 | 폭 3셀(7.5m ≥ 규정 7m) × 길이 40셀(100m) | |
| 진입구 | 1개 (보수적 가정) | 복수 진입구 단지는 최원단 거리 절반 이하 → 본 결과는 안전 측 |
| 통로 위 주차 방향 | 통로와 평행 | 1레인 단위 점유, AGV 이동 축 정렬 |

| 이동 속도 | 기준 1m/s, 민감도 1/2/3m/s | 이동틱 초 = 2.5m ÷ 속도. 3m/s는 Stanley 공개 최대속도이며 평균속도 주장이 아님 |
| 차량 취득/해제 | 미보정 기준 1/1틱, 현실 참조 90/60초 | 현실 참조는 Stanley 공개사양. 취득은 정렬·lift 결합, 해제는 drop 결합 서비스로 모델링 |
| 적치 구역 | 진입구 밖 1개소 (거리 d_s = 15m, 기본) + **통로변 분산 포켓 0~n개(파라미터)** | 소방 동선과 비중첩. **요건: 주차 전용이 불가능한 포장 공간**(진입 광장·놀이터 주변 포장 등 — 순이득 전제, §5). 용량 S는 충분히 크게. 포켓 1개 = 주차면 1면 희생(보수적 하한). 분산 배치 시 T ∝ d² → T ∝ d 복원 |
| 부서공간 | β = 10m = 4셀 (기본값) | 통로 끝에서 클램프 |

## 2. 측정 정의

| 항목 | 정의 |
|---|---|
| 접근 후보 | 단지 입구에서 화재동의 법정 소방자동차 전용구역까지 연결되는 폭 3셀 연속 셀 집합. 같은 종점을 잇는 후보를 2개 이상 비교 |
| 확보 완료 | 선택된 접근 후보 전체에 **폭 3셀 연속 빈 상태**가 달성된 최초 틱. 비선택 통로와 무관한 차량은 이동하지 않음 |
| **측정 시작 (t=0)** | **FMS 트리거 = 119 신고 접수 연동** (기준). 옥외 주차장은 자동화재탐지설비 대상이 아니므로 자동 감지를 전제하지 않음. 화재 위치는 신고 정보 또는 관리사무소 지정. 관리사무소 수동 트리거는 **보조** — 신고보다 이르면 안전 마진, 늦으면 예산 잠식(한계 §6) |
| 시간 예산 | **5/7/9분 도착 시나리오**. 7분은 소방청 도착률 지표에 맞춘 대표 평가값이며 법정 로봇 완료기준이나 화재의 물리 골든타임으로 표현하지 않음 |
| 집계 규칙 | 화재 위치를 스윕해 **위치별 확보시간 곡선(분포 전체)** 을 기본으로, **최원단(최악값)을 헤드라인**으로 병기. "불이 마침 입구 근처에서 났다면"을 전제하지 않는다 |
| 안전 도달 거리 | 확보 시간 ≤ 7분을 만족하는 최대 화재 위치 d (점유 레인별로 산출 — 핵심 산출물) |
| 밀도 | 점유 레인 수(0~3)로 표현. 추가 수용 대수 α 절대값 병기 (1레인 +20대, 2레인 +40대, 3레인 +60대 / 500면 기준 +4/8/12%) |
| 임계값 민감도 | 5/7/9분을 모두 병기. ⚠️ "늦는 지역은 더 빽빽해도 된다"는 서술 금지 — 지역 편차는 어디까지나 불확실성 분석 |
| 회전반경 10m | 판정에서 **제외** (β로 부분 반영). 제외 사실을 리포트에 명시 |
| 시간 단위 | 내부 기록은 이동틱. 현실 프로파일은 pickup/drop을 `ceil(서비스초÷이동틱초)`로 다시 계획한 뒤 초 환산. 단순 `틱×2.5초`는 미보정 알고리즘 기준선으로만 표시 |

## 3. 재배치 규칙

1. **목적지 = 적치 구역.** 만차 전제(통로 주차의 존재 이유) 하에서 빈 주차면은 최악 시나리오에 존재하지 않으므로, 재배치 목적지는 도면에 명시된 전용 공간이어야 한다.
2. **적치 배정 = 화재의 진입구 쪽에 있는 최근접 적치** (규칙 4에 따라 화재 너머 적치는 사용 불가).
3. **접근 순서는 물리 제약이 결정**: 3레인 완전 점유 시 확보 구간 끝단부터만 접근 가능. 1~2레인 점유 시 빈 레인 경유 접근 가능.
4. 화재지점 너머로 차량을 옮기지 않는다 (화재 방향 이동 금지).
5. **로봇 우선순위는 결정론적**: 기본 순서로 함대 계획 → 실패 시 시드 기반 순열로 최대 K회 재시도 → 전부 실패 시 "확보 실패". **재시도 횟수(Attempts)를 지표로 기록** — 병렬성 붕괴의 독립 증거.
6. **S 부족 시 = "확보 실패" + 필요량 기록.** S_필요 = 확보 구간 내 차량 수 = 레인 수 × (d+β)/5m — 결정론적이므로 스윕 불필요, 조건별 산출물로 기록.
7. **포켓 만원 시**: 진입구 방향의 다음 근접 적치로 폴백 (왕복 증가는 모델이 자연 반영). 전 적치 만원 = 확보 실패 + 필요량 기록.
8. **복수 경로 선택**: 후보마다 `EmergencyScenarioV2`와 물리 계획을 독립 생성한다. 성공 후보 중 makespan 최소를 선택하고, 동률이면 이동차량 수→확보 셀 수→이름 순으로 결정론화한다.
9. 보유 운송 유닛이 이동차량보다 많으면 필요한 조만 활성화한다. 남는 유닛을 억지로 움직이거나 개통 경로에 방치하지 않는다.

## 4. 봉투 계산 (D0 재검증 — 상세는 [개발계획서 §0-1](./개발계획서.md))

- 핵심 공식: **N = 레인 수 × (d+β)/5m, T = N × ((d+β) + 2·d_s) ÷ p** [초, 1 m/s]
- **발견**: 왕복 거리가 화재 위치에 종속 → **T는 d의 이차 함수** (기존 "왕복 고정 75초" 가정 폐기)
- 안전 도달 거리 (7분, β=10m, d_s=15m): 3레인 5~23m (p=1~3), 2레인 23~33m (p=2~3), 1레인 ≈68m (p≈4)
- **어떤 점유 수준도 전 구간 100m를 커버하지 못함** (진입구 1개 + 적치 1개소 기준) — 시뮬레이션으로 정밀화

## 6. 명시적 한계 (보수·단순화 가정)

1. 진입구 1개 — 실제 단지는 보통 2개 이상 → 본 결과는 안전 측
2. 적치 구역 1개소·존재 가정 — 3레인 최원단 기준 S_필요 ≈ 60대 ≈ 750㎡로, **이 규모 공터의 존재 자체가 강한 가정** (복수·분산 적치는 후속 확장)
3. 감지 = 신고 동시 — 리드타임은 안전 여유
4. 격자 이산화·노드 이동 근사 — 절대값이 아닌 **조건 간 상대 비교**가 주장의 단위 (속도 민감도로 검증)
5. 회전반경·부서공간은 β로만 근사
6. 실제 운영에서는 그 시점의 빈 주차면도 활용 가능 → 본 결과는 보수적(안전 측)
7. **트리거 연동 지연은 0으로 가정** — 신고접수→FMS 전파의 실제 지연은 별도 검토 필요. 수동 트리거가 신고보다 늦는 경우의 예산 잠식도 모델 밖
8. 신고 위치 정보의 정밀도는 모델에 반영하지 않음 — 불확실할 경우 더 먼 지점을 가정하게 되므로 최악값 집계에 이미 포섭됨. **β는 소방 부서·활동 공간 단일 용도** (오차 마진 겸용 금지 — 파라미터 하나에 의미 하나)
9. 현실 참조 90/60초는 Stanley Robotics 장비 공개사양이며 PARKIE 등 다른 운송 유닛에 일반화하지 않음. 해당 장비를 주장하려면 실제 pickup/drop·평균 주행속도 실측으로 프로파일 교체

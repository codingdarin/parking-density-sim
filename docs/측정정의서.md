### 지상 아파트형 밀도 스윕 집계

- `N=0~14` 전 범위를 실행하며 첫 실패에서 중단하지 않는다. 자동 경로 전환 때문에 차량 수와 시간이 비단조일 수 있다.
- 배치는 하부우선·상부우선·입구부터 교대·화재동부터 교대의 결정론적4종, 화재 위치는 화재동 전면 `(22,5)`, `(22,7)`, `(22,9)`의 대표3점이다.
- 차량 수별 헤드라인은 12조건이 모두 계획 성공이고 420초 이하인 최대 연속 `N`이다. 단일 배치의 최대 성공 `N`을 전체 안전 임계로 표현하지 않는다.
- 적치5면과 확장14면은 별도 레이아웃이다. 확장14면은 추가 적치 위치가 이동거리도 바꾸므로 순수 용량만의 반사실 비교가 아니라 **확장 적치 설계안**으로 명명한다.
- 계획 실패는 적치 부족·중심선 없음·폭 부족·고정 장애물·물리 계획 실패·탐색 상한으로 분리하며, 시간 초과와 합치지 않는다.

### 8동 단지 화재 접근 집계

- 합성 배치는 북측 101~104동·남측 105~108동의 2행×4동이다. 건물 풋프린트는 주행 불가 고정 구조물이고, 동별 전용구역은 항상 비점유한다.
- 각 화재 사건은 해당 동의 전용구역만 종점으로 삼는다. 건물 내부 화염 위치나 층수는 현재 2D 차량 제거 범위를 결정하지 않는다.
- 서문 단일 조건과 서문+동문 조건을 각각 8개 동 전수 실행한다. 복수 진입구 조건은 진입구×상위 K 경로의 물리 개통시간을 모두 비교한다.
- 동별로 선택 입구·후보 수·이동차량 수·틱·초·7분 판정을 기록하며, 성공 동 중 최대 시간을 조건의 헤드라인으로 쓴다. 한 동이라도 계획 실패면 단지 전체 성공으로 집계하지 않는다.
- 5셀 중앙도로는 폭을 3셀로 축소하지 않는다. 폭3 후보가 주차차량 사이로 통과하지 못하도록 두 줄의 가변 차량을 배치하고, 3셀 순환·연결로는 한 줄을 배치한다.

### 8동 단지 가변 차량 밀도 스윕 집계

- 가변 주차 후보22면을 팩토리의 고정 슬롯 순서로 `N=0~22`까지 누적 점유한다. 빈 가변 슬롯은 적치면으로 전용하지 않으며 목적지는 별도 적치12면으로 고정한다.
- 각 N에서 101~108동과 서문+동문 조건을 전수 평가한다. 동별 후보 생성과 물리 계획은 동일하며, 캐시는 차량 점유와 무관한 중심선·폭3 후보에만 적용한다.
- 차량 수별 통과는 8개 동이 모두 계획 성공이고 각각 420초 이하일 때만 참이다. `N=0`부터 끊김 없이 이 조건을 만족하는 최대 N을 **연속 8동 7분 안전 최대 N**으로 기록한다.
- 첫 시간 초과와 첫 계획 실패를 별도 기록한다. 자동 경로·입구 전환으로 결과가 비단조일 수 있으므로 첫 시간 초과에서 스윕을 중단하지 않는다.
- 단일 누적 슬롯 순서는 합성 기준선이지 배치 강건성 결과가 아니다. 강건성은 아래 시드 배치 축으로 별도 집계한다.

### 시드 배치 강건성 집계

- 배치 축은 시드 주입 `System.Random`의 Fisher-Yates 순열로 가변 22면 중 N면을 점유한다(시드 1~12) + 누적 기준선. 같은 시드는 같은 배치를 재현해야 한다(게이트).
- 평가 창은 기준선 임계(N=15) 주변 N=13~17이며, 비단조 가능성 때문에 창 전체를 실행하고 첫 실패에서 중단하지 않는다. 창 밖 N은 시드별로 실행하지 않았음을 명시한다.
- N별 **통과율**(시드 12종 중 8동 전수 7분 통과 비율)과 성공 시드의 최악초 min/중앙/max를 기록하고, **강건 임계 = 창 안에서 전 시드가 통과한 최대 연속 N**으로 정의한다. 누적 기준선 판정은 별도 열로 병기한다.
- 헤드라인은 "누적 기준선 임계 N=15" 단독이 아니라 **강건 임계와 통과율 분포를 병기**해 서술한다 — 단일 배치의 임계를 전체 안전 임계로 표현하지 않는다(기존 원칙의 강건성 확장).

### 실제 단지 A 발췌 블록 집계

- 대상은 1970년대 준공 강남 소재 대단지의 정형 판상 구간이며 산출물·CSV에는 **"실제 단지 A"로 익명화**한다(실명 병기 금지 — §2 윤리 서술 원칙과 동일 결). 근사 상수의 공개 근거: 총 28동·지상 14층·4,424세대·대지 237,900㎡·주차 5,000대(세대당 1.13대)·지하주차장 부재·이중주차로 인한 소방차 진입 지연 보도.
- 발췌는 2×2동 블록이다. 판상 동 길이 ~90m를 60m(24셀)로 절단하고, 골목 도로는 보도된 6m급을 5m(2셀)로 내림 근사한다. **절단은 이동거리를 줄이는 낙관 방향이므로 단지 A 결과는 절대 보장값이 아니라 합성 8동 단지 대비 "기하 유형" 상대 비교로만 서술한다.**
- 배경 만차: 회랑 직각주차열 전량을 이동 가능 슬롯 + 상시 점유로 둔다(로봇 주차장 전환 가정). 가변 밀도 N = 이중주차(종축·진입로·골목 연석 평행 점유) 0~16 결정론적 누적.
- 골목 도로 2셀(5m) < 폭3(7.5m)이므로 **이중주차 0대에서도 연석 주차열의 관리 차량 이동 없이는 개통이 불가능**하다 — 이 기하 성질은 게이트로 고정하고, N별 집계와 별도로 명시한다.
- 집계는 8동 단지와 동일: N=0~16 × 4동 전수(서문+동문), 연속 4동 7분 안전 최대 N을 헤드라인으로, 유닛 4~1조 축 병기.

## 3. 재배치 규칙

1. **목적지 = 적치 구역.** 만차 전제(통로 주차의 존재 이유) 하에서 빈 주차면은 최악 시나리오에 존재하지 않으므로, 재배치 목적지는 도면에 명시된 전용 공간이어야 한다.
2. **적치 배정 = 화재의 진입구 쪽에 있는 최근접 적치** (규칙 4에 따라 화재 너머 적치는 사용 불가).
3. **접근 순서는 물리 제약이 결정**: 3레인 완전 점유 시 확보 구간 끝단부터만 접근 가능. 1~2레인 점유 시 빈 레인 경유 접근 가능.
4. 화재지점 너머로 차량을 옮기지 않는다 (화재 방향 이동 금지).
5. **로봇 우선순위는 결정론적**: 기본 순서로 함대 계획 → 실패 시 시드 기반 순열로 최대 K회 재시도 → 전부 실패 시 "확보 실패". **재시도 횟수(Attempts)를 지표로 기록** — 병렬성 붕괴의 독립 증거.
6. **S 부족 시 = "확보 실패" + 필요량 기록.** S_필요 = 확보 구간 내 차량 수 = 레인 수 × (d+β)/5m — 결정론적이므로 스윕 불필요, 조건별 산출물로 기록.
7. **포켓 만원 시**: 진입구 방향의 다음 근접 적치로 폴백 (왕복 증가는 모델이 자연 반영). 전 적치 만원 = 확보 실패 + 필요량 기록.
8. **복수 경로 선택**: 후보마다 `EmergencyScenarioV2`와 물리 계획을 독립 생성한다. 성공 후보 중 makespan 최소를 선택하고, 동률이면 이동차량 수→확보 셀 수→이름 순으로 결정론화한다.
9. 보유 운송 유닛이 이동차량보다 많으면 필요한 조만 활성화한다. 남는 유닛을 억지로 움직이거나 개통 경로에 방치하지 않는다.

## 4. 봉투 계산 (D0 재검증 — 상세는 [개발계획서 §0-1](./개발계획서.md))

- 핵심 공식: **N = 레인 수 × (d+β)/5m, T = N × ((d+β) + 2·d_s) ÷ p** [초, 1 m/s]
- **발견**: 왕복 거리가 화재 위치에 종속 → **T는 d의 이차 함수** (기존 "왕복 고정 75초" 가정 폐기)
- 안전 도달 거리 (7분, β=10m, d_s=15m): 3레인 5~23m (p=1~3), 2레인 23~33m (p=2~3), 1레인 ≈68m (p≈4)
- **어떤 점유 수준도 전 구간 100m를 커버하지 못함** (진입구 1개 + 적치 1개소 기준) — 시뮬레이션으로 정밀화

## 6. 명시적 한계 (보수·단순화 가정)

1. 기준 통로는 진입구 1개, 8동 합성 단지는 서문 단일/서문+동문을 분리한다. 실제 출동 방향과 개방 상태는 도면·현장 검증 필요
2. 적치 구역 1개소·존재 가정 — 3레인 최원단 기준 S_필요 ≈ 60대 ≈ 750㎡로, **이 규모 공터의 존재 자체가 강한 가정** (복수·분산 적치는 후속 확장)
3. 감지 = 신고 동시 — 리드타임은 안전 여유
4. 격자 이산화·노드 이동 근사 — 절대값이 아닌 **조건 간 상대 비교**가 주장의 단위 (속도 민감도로 검증)
5. 회전반경·부서공간은 β로만 근사
6. 실제 운영에서는 그 시점의 빈 주차면도 활용 가능 → 본 결과는 보수적(안전 측)
7. **트리거 연동 지연은 0으로 가정** — 신고접수→FMS 전파의 실제 지연은 별도 검토 필요. 수동 트리거가 신고보다 늦는 경우의 예산 잠식도 모델 밖
8. 신고 위치 정보의 정밀도는 모델에 반영하지 않음 — 불확실할 경우 더 먼 지점을 가정하게 되므로 최악값 집계에 이미 포섭됨. **β는 소방 부서·활동 공간 단일 용도** (오차 마진 겸용 금지 — 파라미터 하나에 의미 하나)
9. 현실 참조 90/60초는 Stanley Robotics 장비 공개사양이며 PARKIE 등 다른 운송 유닛에 일반화하지 않음. 해당 장비를 주장하려면 실제 pickup/drop·평균 주행속도 실측으로 프로파일 교체
10. 지상형 밀도 결과의 화재 위치는 화재동 전면 대표3점이며 모든 floor 셀 또는 실제 동별 출입구를 전수 조사한 결과가 아님
11. 8동 단지의 500~1,000세대·12m 주진입도로 가정은 합성 설계값이다. 실제 총세대수와 사업승인 도면에 따라 8/15/20m급 진입도로 조건을 별도 생성해야 한다.
12. 실제 단지 A 블록은 공개 자료 기반 발췌·근사이며 사업승인 도면 실측이 아니다. 동 길이 절단(낙관 방향)·도로 폭 내림(보수 방향)이 혼재하므로 절대값 주장을 금지하고, 전 단지 28동으로의 일반화는 진입구·간선 구조 반영이 선행돼야 한다.
